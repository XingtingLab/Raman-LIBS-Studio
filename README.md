# Raman-LIBS Studio

请在 [GitHub Releases](https://github.com/XingtingLab/Raman-LIBS-Studio/releases) 中选择对应平台的下载包。

Raman-LIBS Studio 用于分析拉曼和 LIBS 光谱，支持峰拟合、面扫、线扫、原位、偏振及多组比较。

## 下载与启动

| 平台 | 选择的文件 | 启动方式 |
| --- | --- | --- |
| macOS · Apple 芯片（M 系列） | `Raman-LIBS_Studio-1.6.6-AppleSilicon.dmg` | 打开 DMG，把 App 拖到「应用程序」。 |
| macOS · Intel 处理器 | `Raman-LIBS_Studio-1.6.6-Intel.dmg` | 打开 DMG，把 App 拖到「应用程序」。 |
| Windows 10 / 11 · x64 | `Raman-LIBS_Studio-1.6.6-Windows-x64.zip` | 选择「全部解压缩」，双击 `Raman-LIBS 1.6.6.exe`。将 `_internal` 与 EXE 保留在同一目录。 |

两种 Mac 版均需要 macOS 12.3 或更新版本。每个下载包内都附有对应平台的《使用说明》。

## 快速上手

1. 点击「打开…」，或把光谱文件或文件夹拖入窗口。单条拉曼光谱可以打开 `.txt` 文件。
2. 做多组对比或 LIBS 分析时，打开上一级目录，每个子文件夹放一组数据。
3. 做拉曼峰拟合时，输入或选择峰位，点击「对全部光谱执行峰拟合」。用「导出数据」保存表格，或用「复制论文图」复制图像。

1.6.6 改善了框选、平移、缩放和拖动峰标记时的谱图响应。
